# Contribuir

1. Crea una rama `feature/<tema>`.
2. Agrega o modifica escenarios en `data/scenarios.json`.
3. Cada escenario debe incluir: ID, dominio, título, nivel, tipos, técnica, herramientas, precondiciones, pasos, resultado, automatización, riesgo, etiquetas y estándar.
4. Evita credenciales, nombres de clientes, IP, URLs internas o datos sensibles.
5. Abre un pull request con evidencia de revisión local.

## Criterio de aceptación
- Contenido técnicamente revisado.
- Enlaces oficiales.
- Lenguaje claro y accionable.
- Sin instrucciones ofensivas contra activos no autorizados.
- Diseño responsive y navegación por teclado preservados.
